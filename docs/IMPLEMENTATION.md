# Blackjack Cheater 实现与验收说明

本项目根据随任务提供的 GDD 重建，全部源码、依赖、测试、截图、便携包和游戏存档均位于 本工程根目录下。编码主要由 DeepSeek 子代理承担，主代理负责集成、独立规则验收及打包。

## 已接入的生产功能

- 基础、困难与酒吧模式；三阶段推进、下注、要牌、停牌、加倍、投降、结算、商店、熔炉与进度保存。
- 标准与特殊牌组、逐张 UID 牌靴、弃牌回收、墨水与特种标记、钓具、五类庄家出千和指认。
- 139 件遗物定义，其中按 GDD 排除 4 件偏置遗物；遗物算分、主动能力、消耗次数、跨回合寄存和职阶模块。
- 玩家和困难庄家职阶；14 步带动作门槛的教程；通关解锁的冠军牌组编辑器。
- 酒吧的 34 款技能、选牌交互、酒杯与宿醉、100 回合推进、结局、200 条通用文案与每款酒专属文案。
- 中文界面、窗口与全屏、键鼠操作、程序化图形与合成音频；存档使用游戏目录旁的 saves21。

## 规格解释及素材边界

自然 Blackjack 按原文返还 1.5 倍下注。冠军牌池按可核对的附录分项合计 345 张，而非正文中的 290。指认额外允许在庄家行动时使用，以支持对后续发生的出千作出反应。详细解释见 SPEC-DECISIONS.md。

附件没有原版源码、酒保立绘、酒水图片和音乐。本次使用新绘制的程序化视觉、合成音效与 Noto Sans SC 字体，不声称原版素材复刻。

情报计算有显式边界：骰子等未确定值及超出递归预算的情况显示未知；部分自定义数值牌不纳入庄家后续递归并报告覆盖缺口。递归概率不会替代游戏实际发牌逻辑。钓具通过现有情报面板的已标记牌点击入口操作，面板有选择提示；没有独立钓具窗口，尚无专门的钓具图形自动化场景。1920×1080 采用同一缩放布局，但本次未单独截图验收。

## 验证证据

统一规则入口为 Verify.bat，报告写入 artifacts/verification.json，各套件详细日志写入 artifacts/verify_*.log。这些规则测试使用真实 LuaJIT 与显式的最小 LOVE 宿主替身，不等同图形验证。实际 LÖVE 窗口运行和输入脚本另行记录。

最终规则回归：10 个套件共 457 项通过、0 失败，另有全部 66 个 Lua 文件语法检查通过。分项为核心 132、独立规则 18、流程 18、概率 27、酒吧 61、教程/编辑器 21、职阶 33、遗物 22、算分 75、整局压力 50。压力套件覆盖普通/困难各 20 个种子、酒吧 5 个种子及附加不变量检查；通过的周目可合法失败退场，不意味着这些随机策略均通关。

真实 LÖVE 图形验收：1280×720 与 800×600 各完成 20 个场景、0 失败；包含标题进入游戏、遗物选择、下注、要牌/停牌/继续的键鼠回调，以及设置/情报/教程的输入隔离验证。记录见 artifacts/smoke_all_1280.txt 与 artifacts/smoke_all_800.txt。便携 EXE 内运行同一核心套件，132 项通过、0 失败（artifacts/packaged_test.log），标题场景烟测见 artifacts/packaged_smoke.log。

遗物审计的逐项状态与行为测试边界见 relic-audit.md；不能将定义数量或处理器注册数量当作逐件数值断言数量。所有测试数量以最终实际运行记录为准，不沿用 GDD 原版工程的测试数字。

## 重建与许可

Build.bat 使用 Python 标准库构建 .love、含 LÖVE 运行时的 Windows x64 便携目录和 ZIP；dist/manifest.json 保存体积与 SHA-256。游戏运行无需 Python。第三方许可见根目录 LICENSES.md，Windows 包另附 LÖVE 与字体许可全文。
