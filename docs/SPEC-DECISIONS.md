# 规格解释与重建边界

本项目的输入是 GDD_BlackjackCheater.md；没有原版工程、测试或素材。GDD 内“已实现”的表述是对其原版项目的描述，不是本次重建的验收记录。本次验证以 artifacts 下实际生成的日志与截图为准。

## 确认采用的规则

- 引擎采用 LÖVE 11.5 / LuaJIT，保留键鼠操作、中文界面与 Windows 本地运行。
- 起始筹码 2500，三阶段目标 2000 / 20000 / 2000000，阶段轮数 15 / 15 / 30。
- 自然 Blackjack 的“返还金额”按 GDD 公式为下注的 1.5 倍，不擅自改成常见赌场规则的 2.5 倍。下注已经在开始时扣除。
- 只有真实改变过牌的出千行为才能被成功指认。虚假痕迹、未满足条件的招式不视为出千。
- 4 件暗中偏置抽牌序列的遗物保留定义但排除出可抽取池。
- 冠军牌池按附录 C4 逐项牌面构造：52+44+40+40+8+3+52+52+52+1+1=345。文档写的合计 290 与其分项不一致，采用可核对的分项定义。
- GDD 第22章列出的重复教程键、重复回合事件等明显程序缺陷不作为必须复制的游戏特性。

## 未取得的原版资产

原版酒保与酒水 PNG、阶段 MP3、标题字体均未随文档提供。此工程采用程序化重绘与合成音效；不宣称视觉或音频逐像素复刻。具体交付覆盖与已知差异记录在 IMPLEMENTATION.md。
